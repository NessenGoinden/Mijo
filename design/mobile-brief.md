## Cadre
- Frame **390 × 844** (iPhone 15/16 ordinaire), fond `bg/cream`, auto layout vertical, `clipsContent` ; barre d'état simulée 54 px (heure « 9:41 » Body/S Bold, icônes réseau/batterie simplifiées en encre) ; zone basse 34 px pour l'indicateur d'accueil (trait encre 134 × 5 centré). Contenu défilant : les écrans longs peuvent être en hauteur « hug » (comme sur desktop) mais la barre d'onglets reste dessinée en bas de la zone visible : pour les écrans longs, produire la version **hauteur 844** avec le contenu coupé (la barre d'onglets visible) ; une seconde version pleine hauteur n'est pas nécessaire.
- Marges latérales 16 px ; grille 8 pt ; cibles ≥ 44 px pour tout élément interactif ; textes ≥ 16 px sauf métadonnées 14 px et Labels 12 px.
- Typo : Display/L (40) pour l'accueil et la fiche, Title/M (28) pour les titres de page, Title/S (20) pour les cartes, Body/M 16, Body/S 14, Cuisine/Étape 24/32 en mode cuisine (styles existants, Bricolage + DM Sans via les styles).
- Couleurs : crème + forêt en repères ; deux accents saturés max par écran (soleil + tomate/forêt) ; texte blanc sur tomate, encre sur soleil/carotte/kiwi/rose/sauge, crème sur forêt/prune.
- Photos : `design/photos-hashes.json` (fills IMAGE, scaleMode FILL) ; Omelette et Tofu en couverture graphique (surface kiwi pâle/sauge + Vapeur + initiale).
- Aucun visage, aucune mascotte. Aucun emoji dans les textes.
